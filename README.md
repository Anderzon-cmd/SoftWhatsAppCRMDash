 **E-commerce mediante WhatsApp con CRM Integrado y Generación Automática**

## **Overview**
Este software combina las ventajas de un e-commerce conectado a WhatsApp con la potencia de la inteligencia artificial para automatizar procesos clave. Además de integrar un CRM avanzado con análisis semántico, el sistema utiliza IA para generar catálogos personalizados, gestionar cotizaciones dinámicas y optimizar el proceso de compra.

## **Características principales**
1. **Integración con WhatsApp:**
   - Comunicación directa con clientes mediante WhatsApp Business API.
![Catálogo generado por IA](https://res.cloudinary.com/dkqyigiyi/image/upload/v1736438619/uaafwajpvlejvrwilz8i.jpg)
2. **Generación automática de catálogos:**
   - Creación de catálogos dinámicos basados en las preferencias.

3. **Gestión inteligente de cotizaciones:**
   - Cálculo de cotizaciones en tiempo real según los productos seleccionados.
   - Envío automatizado de cotizaciones detalladas directamente en WhatsApp.

4. **Automatización del proceso de compra:**
   - Flujo automatizado que guía al cliente desde la selección del producto hasta el pago.
   - Integración con pasarelas de pago para una experiencia fluida.
![Proceso de compra automatizada](https://res.cloudinary.com/dkqyigiyi/image/upload/v1736438618/gm0yr4dlahdt2tk2wfmy.jpg)
5. **Análisis de Lenguaje Natural (NLP):**
   - Identificación de sustantivos y verbos clave en conversaciones para comprender las intenciones del cliente.
   - Priorización de solicitudes y resolución automática de preguntas frecuentes.
![Analisis de texto](https://res.cloudinary.com/dkqyigiyi/image/upload/v1736438509/f8a138dmtxzexplvqkpu.png)

6. **CRM con análisis semántico:**
   - Seguimiento avanzado de interacciones con clientes.
   - Generación de insights a partir de patrones de conversación para mejorar las estrategias de venta.

7. **Desactivación de conversaciones:**
   - Para una atencion personalizada al cliente.
